    SOFA — Module

    Standards of Fundamental Astronomy (SOFA)

    Version: 2023-10-11 (Release 19)

    Pure Julia implementation of the IAU SOFA library, migrated from the Astrometry.SOFA submodule of Astrometry.jl.

    source

    The API mirrors the SOFA C library, organized into the topical pages listed in the sidebar. Function names match their SOFA C counterparts with the iau prefix removed, so e.g. iauCal2jd becomes cal2jd.
